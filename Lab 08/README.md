# Laboratorio 08

Patrones Factory Method y Observer aplicados al sistema de registro y matrícula de estudiantes del proyecto del curso.

## Compilación

Desde la raíz de `Lab 08`:

```sh
g++ Avance02/antes.cpp -o Avance02/antes.exe
g++ Avance02/main.cpp -o Avance02/main.exe
g++ Avance04/main.cpp -o Avance04/main.exe
```

## Ejecución

```sh
./Avance02/antes.exe
./Avance02/main.exe
./Avance04/main.exe
```

`Avance02/antes.cpp` es el código sin patrón y `Avance02/main.cpp` el mismo sistema con `PersonaFactory`. `Avance04` agrega el patrón Observer en `SistemaMatricula`.

Los avances 1, 3 y 5 son explicaciones y diagramas que se desarrollan en el informe.
